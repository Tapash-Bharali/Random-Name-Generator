# 🎲 Random Name Generator

A simple and beginner-friendly JavaScript project that randomly displays a name from a predefined list whenever the button is clicked.

## 🚀 Features

- Generate a random name with a single click
- Clean and responsive interface
- Built using HTML, CSS, and JavaScript
- Great project for learning DOM manipulation and event handling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 💡 How It Works

- A list of names is stored in a JavaScript array.
- When the user clicks the **Generate** button:
  - A random index is generated using `Math.random()`.
  - The corresponding name is selected.
  - The selected name is displayed on the page.
